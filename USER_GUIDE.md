# Руководство пользователя OpenTFC
## Open Table Filter, Charts & Spreadsheets for Atlassian Confluence

**OpenTFC** — это открытый многофункциональный набор макросов для Atlassian Confluence Data Center и Server (версии 8.5 LTS – 9.x), предназначенный для фильтрации, сортировки, визуализации, агрегации и преобразования табличных данных любой сложности.

Плагин является полноценной альтернативой коммерческому решению *Table Filter, Charts & Spreadsheets* от Stiltsoft и полностью совместим со структурой страниц и именами макросов.

## 1. Обзор макросов

OpenTFC включает 9 специализированных макросов, разделенных на две категории:

### Макросы-контейнеры (обрабатывают вложенные таблицы):
| Макрос | Имя в редакторе | Алиасы | Назначение |
| :--- | :--- | :--- | :--- |
| **Open Table Filter** | `opentfc-table-filter` | `open table filter`, `table-filter` | Фильтрация, сортировка, поиск, пагинация, скрытие колонок, итоги, экспорт в Excel/CSV |
| **Open Chart from Table** | `opentfc-chart` | `open-chart`, `table-chart`, `chart` | 15+ видов диаграмм на базе Apache ECharts с динамическим обновлением от фильтров |
| **Open Pivot Table** | `opentfc-pivot` | `open-pivot`, `pivot-table` | Сводные таблицы с многоуровневой группировкой и агрегацией |
| **Open Table Transformer** | `opentfc-transformer` | `open-table-transformer`, `table-transformer` | Объединение, фильтрация и вычисления над таблицами с помощью чистого SQL (DuckDB) |

### Макросы-генераторы данных (создают таблицы):
| Макрос | Имя в редакторе | Алиасы | Назначение |
| :--- | :--- | :--- | :--- |
| **Open Table Spreadsheet** | `opentfc-spreadsheet` | `open-spreadsheet`, `table-spreadsheet` | Встроенный табличный процессор с формулами, стилями ячеек и сохранением в XLSX |
| **Open Spreadsheet Include** | `opentfc-spreadsheet-include` | `spreadsheet-include` | Рендеринг указанного листа/диапазона ячеек из прикрепленного файла Excel |
| **Open Attachment Table** | `opentfc-attachment-table` | `attachments-table` | Автоматическая интерактивная таблица вложений текущей страницы |
| **Open CSV Table** | `opentfc-csv` | `csv-table` | Парсинг и отображение файлов CSV/TSV из вложений или URL |
| **Open JSON Table** | `opentfc-json` | `json-table` | Преобразование структурированных данных JSON в таблицу |

## 2. Как добавить макрос на страницу

1. Откройте нужную страницу Confluence в режиме **Редактирования** (`Edit` или клавиша `e`).
2. Добавить макрос можно любым из трех способов:
   - **Способ 1 (Слэш-меню):** В новой строке введите символ `/` и начните печатать название, например `/filter`, `/chart`, `/pivot` или `/sql`. Выберите нужный макрос из списка.
   - **Способ 2 (Фигурные скобки):** Введите `{` и наберите `opentfc` или `table-filter`.
   - **Способ 3 (Панель инструментов):** Нажмите кнопку **«+» (Вставить дополнительное содержимое)** на верхней панели редактора → выберите **«Другие макросы»** (Other Macros) → в поле поиска введите `OpenTFC` или перейдите в категорию *«Форматирование»* или *«Отчеты»*.
3. Для макросов-оберток (Filter, Chart, Pivot, Transformer):
   - После добавления макроса на страницу поместите внутрь его рамки вашу таблицу Confluence (или другой макрос OpenTFC).

## 3. Подробное руководство по макросам

### 3.1. Open Table Filter

Макрос превращает статическую HTML-таблицу Confluence в интерактивный инструмент анализа данных уровня Excel или BI-систем.

```
+-------------------------------------------------------------+
| [Поиск по всем колонкам...]  [Колонки v]  [Экспорт v] [Виды v] |
| Статус: [ Все v ] | Отдел: [ Разработка, Тестирование v ]   |
+-------------------------------------------------------------+
| ID   | Сотрудник       | Отдел         | Оклад      | Статус |
+------+-----------------+---------------+------------+--------+
| 101  | Иванов Иван     | Разработка    | 180 000 ₽  | Актив  |
| 102  | Петрова Анна    | Тестирование  | 140 000 ₽  | Актив  |
+-------------------------------------------------------------+
| Итого: 2 строки        |               | 320 000 ₽  |        |
+-------------------------------------------------------------+
```

#### Параметры макроса в редакторе:
- **Показывать строку глобального поиска** (`showSearchBox`): Поле быстрого поиска по любому тексту во всей таблице.
- **Показывать фильтры колонок** (`showColumnFilters`): Панель выпадающих списков и фильтров над таблицей.
- **Закреплять заголовок** (`stickyHeader`): Заголовок таблицы остается видимым при прокрутке страницы вниз.
- **Закреплять первые колонки** (`freezeColumns`): Число левых колонок (например, `1` или `2`), которые не скроллятся по горизонтали.
- **Показывать строку итогов** (`showTotals`): Добавляет нижнюю строку с вычислением сумм (`SUM`), средних (`AVG`), минимумов (`MIN`), максимумов (`MAX`) или количества записей (`COUNT`).
- **Разрешить скрытие колонок** (`allowHideColumns`): Выпадающее меню с чекбоксами для показа/скрытия столбцов пользователем.
- **Кнопки экспорта** (`showExportButtons`): Кнопки выгрузки в Excel (XLSX) и CSV.
- **Количество строк на странице** (`pageSize`): По умолчанию `25` (доступны варианты: 10, 25, 50, 100, Все).

#### Работа с фильтрами в режиме просмотра:
- **Текстовый фильтр:** Введите подстроку для поиска. Поддерживается поиск без учета регистра.
- **Выпадающий список (Множественный выбор):** Кликните по названию колонки в блоке фильтров и отметьте галочками нужные значения.
- **Числовой диапазон:** Для колонок с числами отображаются поля «От» и «До».
- **Диапазон дат:** Интерактивный календарь для выбора начальной и конечной даты.
- **Мультисортировка:** Клик по заголовку сортирует колонку (по возрастанию / по убыванию). Для сортировки по нескольким колонкам удерживайте клавишу `Shift` при клике на второй и последующие заголовки!
- **Сохранение персональных видов (Custom Views):**
  - Настройте необходимые фильтры, видимость колонок и порядок сортировки.
  - Нажмите кнопку **«Сохранить вид»** (Save View), введите имя профиля.
  - Профиль сохранится в базе данных Confluence для вашей учетной записи. Вы всегда сможете быстро переключаться между сохраненными представлениями в один клик.

### 3.2. Open Chart from Table

Превращает данные любой таблицы Confluence в наглядные интерактивные диаграммы с помощью высокопроизводительного движка **Apache ECharts**.

#### Доступные типы графиков:
- **Column / Bar (Столбчатая / Линейчатая):** Сравнение показателей по категориям.
- **Stacked Column / Bar (С накоплением):** Доли и общий объем в категориях.
- **Line / Area (Линейный график / С областями):** Динамика показателей во времени.
- **Pie / Donut (Круговая диаграмма / Кольцевая):** Процентное соотношение долей.
- **Scatter (Точечная диаграмма):** Выявление корреляций между числовыми величинами.
- **Radar (Лепестковая диаграмма):** Оценка многомерных характеристик (компетенции, KPI).
- **Funnel (Воронка):** Этапы конверсии продаж или процессов.
- **Gantt (Диаграмма Ганта):** Графики этапов проектов и сроков задач.

#### Основные параметры:
- **Тип диаграммы** (`chartType`): Выбор одного из поддерживаемых типов.
- **Колонка категорий (X-ось)** (`categoryColumn`): Название столбца, значения которого пойдут по горизонтальной оси (или сегменты круговой диаграммы).
- **Колонки значений (Y-оси)** (`valueColumns`): Один или несколько столбцов с числами через запятую (например, `План, Факт, Отклонение`).
- **Операция агрегации** (`aggregation`): `SUM`, `AVG`, `COUNT`, `MIN`, `MAX` или `NONE` (без агрегации, вывод всех строк).
- **Высота диаграммы** (`height`): Высота блока в пикселях (по умолчанию `400px`).
- **Заголовок** (`title`): Название диаграммы над графиком.

> [!TIP]
> **Связка с Open Table Filter:**
> Если поместить `Open Chart` внутрь `Open Table Filter`, диаграмма будет **автоматически перерисовываться в реальном времени** при любом изменении фильтров пользователем!

### 3.3. Open Pivot Table

Позволяет создавать аналитические сводные таблицы из плоских списков данных прямо в Confluence без необходимости экспорта в Excel.

#### Как настроить:
1. Оберните таблицу макросом `Open Pivot Table`.
2. В параметрах укажите:
   - **Поля строк (Rows):** Колонки, по которым будет строиться вертикальная группировка (например, `Регион`, `Город`).
   - **Поля столбцов (Columns):** Колонки для горизонтальной группировки (например, `Квартал` или `Год`).
   - **Поля значений (Values):** Числовая колонка для расчета (например, `Сумма продаж`).
   - **Функция агрегации (Aggregation):**
     - `SUM` — сумма
     - `COUNT` — количество строк
     - `AVERAGE` — среднее арифметическое
     - `MIN` / `MAX` — минимальное или максимальное значение
3. В режиме просмотра вы можете сворачивать и разворачивать подуровни группировки кликом по значкам `+` / `-`.

### 3.4. Open Table Transformer

Мощнейший инструмент для инженеров данных, аналитиков и руководителей проектов. Позволяет писать произвольные **SQL-запросы** к одной или нескольким таблицам Confluence, используя встроенный in-memory движок **DuckDB**.

#### Обозначение таблиц в запросе:
- Первая вложенная таблица обозначается как `T1`.
- Вторая — `T2`, третья — `T3` и так далее.
- Если имена колонок содержат пробелы или кириллицу, заключайте их в двойные кавычки: `"Сумма заказа"`, `"Дата"`.

#### Примеры SQL-запросов:

1. **Группировка и подсчет итогов:**
```sql
SELECT
    "Отдел",
    COUNT(*) AS "Количество сотрудников",
    ROUND(AVG("Зарплата"), 2) AS "Средняя зарплата",
    SUM("Зарплата") AS "Общий ФОТ"
FROM T1
WHERE "Статус" = 'Активен'
GROUP BY "Отдел"
ORDER BY "Общий ФОТ" DESC;
```

2. **Объединение двух таблиц (LEFT JOIN):**
*Задача: сопоставить список задач из T1 с именами исполнителей из справочника T2 по полю `User_ID`.*
```sql
SELECT
    t1."Задача",
    t1."Приоритет",
    t2."ФИО" AS "Исполнитель",
    t2."Email"
FROM T1 t1
LEFT JOIN T2 t2 ON t1."User_ID" = t2."ID"
ORDER BY t1."Приоритет" ASC;
```

3. **Слияние таблиц (UNION ALL):**
*Задача: объединить отчеты за 1-й и 2-й кварталы в единую сводку.*
```sql
SELECT 'Q1' AS "Период", * FROM T1
UNION ALL
SELECT 'Q2' AS "Период", * FROM T2;
```

4. **Вычисляемые поля и условия (CASE):**
```sql
SELECT
    "Номер договора",
    "Сумма",
    CASE
        WHEN "Сумма" > 1000000 THEN 'Крупный клиент'
        WHEN "Сумма" > 300000 THEN 'Средний бизнес'
        ELSE 'Розница'
    END AS "Категория сделки"
FROM T1;
```

> [!NOTE]
> Запросы выполняются в изолированной песочнице с защитой от изменения данных (разрешены только `SELECT` запросы, DDL и файловый I/O заблокированы).

### 3.5. Open Table Spreadsheet

Полнофункциональные электронные таблицы со знакомым интерфейсом Excel прямо на странице Confluence.

#### Возможности:
- **Формулы:** Поддержка математических, статистических и логических функций (`SUM`, `AVERAGE`, `COUNT`, `IF`, `VLOOKUP`, `CONCATENATE` и др.).
- **Стилизация:** Настройка шрифтов, заливки ячеек, цвета текста, выравнивания, границ ячеек.
- **Форматы чисел:** Финансовый, процентный, дата/время, разделители тысяч.
- **Управление структурой:** Добавление и удаление строк и колонок, объединение ячеек (`Merge Cells`), изменение ширины и высоты.
- **Хранение данных:** Таблица сохраняется как стандартный `.xlsx` файл во вложениях страницы. При каждом сохранении создается новая версия файла в истории версий Confluence, что гарантирует сохранность данных.
- **Защита от конфликтов:** При открытии таблицы на редактирование включается мягкая блокировка сессии с отображением предупреждения другим пользователям.

### 3.6. Open Spreadsheet Include

Позволяет отобразить на странице Confluence лист или конкретный диапазон ячеек из любого файла Excel (`.xlsx`), прикрепленного к странице.

#### Параметры:
- **Файл вложения** (`attachmentName`): Имя прикрепленного `.xlsx` файла (например, `План_2026.xlsx`).
- **Имя листа** (`sheetName`): Название листа (если не указано, берется первый лист).
- **Диапазон ячеек** (`range`): Например, `A1:G25` (если не указан, отображается весь заполненный лист).
- **Показывать сетку** (`showGrid`): Включение отображения границ ячеек.

### 3.7. Open Attachment Table

Автоматически строит красивую, структурированную таблицу всех прикрепленных к странице файлов.

#### Параметры:
- **Фильтр по расширениям** (`fileExtensions`): Список расширений через запятую (например, `pdf, xlsx, docx`).
- **Маска имени файла** (`namePattern`): Регулярное выражение или подстрока (например, `Отчет_*`).
- **Колонки для отображения**: Имя файла, размер, дата изменения, автор, версия, прямая ссылка на скачивание.

Таблицу вложений можно обернуть в `Open Table Filter`, чтобы получить мгновенный поиск по файлам на страницах с десятками документов!

---

### 3.8. Open CSV Table

Позволяет вставлять данные из CSV или TSV файлов без ручного переноса.

#### Параметры:
- **Источник данных** (`sourceType`):
  - `attachment` — файл из вложений страницы;
  - `url` — внешний веб-адрес (поддерживает внутренние корпоративные хранилища с SSRF-защитой).
- **Разделитель колонок** (`delimiter`): Автоопределение, запятая (`,`), точка с запятой (`;`), табуляция (`\t`) или вертикальная черта (`|`).
- **Кодировка** (`encoding`): `UTF-8`, `Windows-1251` (ANSI), `ISO-8859-1`.
- **Первая строка — заголовки** (`hasHeader`): `true`/`false`.

---

### 3.9. Open JSON Table

Преобразует массивы JSON-объектов в удобную для чтения таблицу Confluence.

#### Параметры:
- **JSONPath путь** (`jsonPath`): Путь к массиву объектов (например, `$.data.items[*]`).
- **Выбор колонок** (`columns`): Список ключей JSON, которые нужно включить в таблицу.
- Поддерживает парсинг многоуровневых вложенных структур.

## 4. Комбинирование макросов

Главная сила OpenTFC — поддержка конвейерной обработки данных (**Chaining Pipeline**). Вы можете вкладывать макросы друг в друга для решения комплексных аналитических задач.

### Пример 1: Фильтрация результатов SQL-трансформации
```
+--- Open Table Filter -------------------------------------+
|  +--- Open Table Transformer (SQL) --------------------+  |
|  |  SELECT t1."Отдел", SUM(t1."Сумма") AS "Итого"      |  |
|  |  FROM T1 GROUP BY t1."Отдел"                        |  |
|  |  +--- Исходная таблица Confluence ---------------+  |  |
|  |  | [ Данные по продажам за год ]                 |  |  |
|  |  +-----------------------------------------------+  |  |
|  +-----------------------------------------------------+  |
+-----------------------------------------------------------+
```
*Результат:* SQL объединяет данные, а родительский фильтр добавляет мгновенный поиск, сортировку и экспорт в Excel.

### Пример 2: Диаграмма по отфильтрованным данным
```
+--- Open Table Filter -------------------------------------+
|  [ Фильтр: Выберите Регион = "Северо-Запад" ]             |
|  +--- Open Chart from Table ---------------------------+  |
|  |  Тип: Pie (Круговая), Категория: Продукт, Сумма     |  |
|  |  +--- Таблица продуктов и продаж ----------------+  |  |
|  |  | ...                                           |  |  |
|  |  +-----------------------------------------------+  |  |
|  +-----------------------------------------------------+  |
+-----------------------------------------------------------+
```
*Результат:* Пользователь выбирает регион в фильтре — круговая диаграмма мгновенно пересчитывает доли продуктов для выбранного региона.

## 6. Экспорт страниц в PDF / Word

При экспорте страницы Confluence через стандартное меню (`...` → **Экспорт в PDF** или **Экспорт в Word**):
- Все макросы OpenTFC автоматически переключаются в режим статической печати:
  - Форматированные таблицы сохраняют красивый вид, сетку, выравнивание и шрифты.
  - Скрытые интерактивные панели фильтров и кнопки управления скрываются, чтобы не загромождать печатный документ.
  - Диаграммы рендерятся в векторном/высоком растровом разрешении без обрезки краев.

## 7. Часто задаваемые вопросы (FAQ)

#### В: Совместим ли OpenTFC со страницами, на которых ранее использовался Stiltsoft Table Filter?
**О:** Контент Stiltsoft (макросы `table-filter`, `pivot-table` и т.п.) требует ручной конвертации: начиная с v1.0.1 имена без префикса `open-*` намеренно удалены — дубли со встроенным Chart-макросом Confluence и макросами других приложений срывали активацию плагина (инцидент 27–28.10.2026). Собственные макросы OpenTFC регистрируются как `opentfc-*` и с алиасами `open-*`.

#### В: Что делать, если Confluence 8.5 пишет «Нет метаданных макроса»?
**О:** Убедитесь, что установлена последняя версия плагина `v1.0.1` или новее. В этой версии исправлены дескрипторы для полной совместимости с Confluence 8.5 LTS – 9.x, а на странице `/plugins/servlet/opentfc/diagnostics` видны все события активации и ошибки.

#### В: Где сохраняются настройки видов и фильтров пользователя?
**О:** Персональные виды пользователей сохраняются в служебных таблицах Active Objects внутри базы данных Confluence, привязанных к `Page ID` и логину пользователя. Это не изменяет текст страницы и не создает лишних ревизий в истории страницы.

#### В: Безопасен ли SQL в Open Table Transformer?
**О:** Да. Используется движок DuckDB в режиме read-only. Любые попытки выполнения команд изменения схемы (`DROP`, `ALTER`, `CREATE`), модификации данных (`INSERT`, `UPDATE`, `DELETE`) или обращения к файловой системе сервера блокируются валидатором AST и песочницей DuckDB.
