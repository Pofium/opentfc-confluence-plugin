Two-stage build: first `npm install && npm run build` (Webpack production) to emit the frontend assets, then `mvn package` / `atlas-mvn package` to produce `target/opentfc-confluence-plugin-1.0.4.jar`; `mvn test` runs ~109 unit tests with JaCoCo coverage, and `mvn verify` additionally validates the OBR artifact and plugin manifest. GitHub Actions CI runs `npm run check`, frontend build, and `mvn verify` on JDK 17.
