The root is an Atlassian AMPS Maven project (`pom.xml`, `packaging=atlassian-plugin`) that assembles all Java sub-modules plus a TypeScript frontend bundle. The frontend (ag-grid + echarts) is built by Webpack via `package.json` scripts and shipped alongside the Java plugin; the backend uses Confluence 8.5/9.x APIs, Active Objects for profile persistence, DuckDB JDBC for in-memory SQL, Apache POI for XLSX export, Jackson for JSON, and Jsoup for HTML parsing. A companion standalone servlet plugin (`opentfc-diag-lite.jar`) is published separately under `.github/workflows` CI artifacts and exposes `/plugins/servlet/diag-lite` to diagnose host state when the main plugin fails to activate. Dependency versions are centralized in the root `pom.xml` `<properties>` and `<dependencyManagement>` so every child module shares the same JDK 17, Jackson, POI, commons-csv, duckdb, and jsoup versions. OSGi imports are explicitly declared in the AMPS `<Import-Package>` block with `resolution:=optional` only for subsystems guarded at runtime, avoiding the previous catch-all wildcard that masked activation failures.
