# Руководство по установке и приёмке OpenTFC

Данный документ описывает процедуру сборки, развертывания на инстансе Atlassian Confluence Data Center (версии 8.5 LTS – 9.x) и проведения приёмочных испытаний по Smoke-чеклисту ТЗ (раздел 12.3).

> **Статус приёмки.** Юнит-тесты backend (109 тестов, покрытие строк ~90 %) и сборка артефакта проверены локально и в CI. Пункты smoke-чеклиста, помеченные «Инстанс», выполняются на живом Confluence с установленным JAR — в рамках автотестов они не проверялись и должны быть подтверждены при приёмке.

---

## 1. Системные требования
- **Confluence DC:** 8.5.x LTS или 9.x (включая кластерный режим 2+ ноды)
- **Java:** JDK 17
- **Node.js:** 18+ и npm
- **Сборщик:** Atlassian Plugin SDK (`atlas-mvn`) или Apache Maven 3.8+

---

## 2. Сборка плагина

### Шаг 1: Сборка фронтенд-ассетов
```bash
npm install
npm run build
```
Команда компилирует TypeScript и CSS, формируя production-бандлы:
- `src/main/resources/js/opentfc.bundle.js`
- `src/main/resources/css/opentfc.bundle.css`

### Шаг 2: Сборка P2-артефакта (JAR)
```bash
atlas-mvn clean package -DskipTests=false
```
или стандартным Maven:
```bash
mvn clean package
```
Результат сборки:
`target/opentfc-confluence-plugin-1.0.0-SNAPSHOT.jar`

### Шаг 3: Юнит-тесты и покрытие
```bash
mvn test      # 109 тестов; покрытие: target/site/jacoco/index.html
mvn verify    # тесты + JAR + OBR + валидация манифеста плагина
```

---

## 3. Развертывание в Confluence Data Center

1. Перейдите в веб-интерфейс Confluence с учетной записью системного администратора.
2. Откройте **Настройки Confluence (⚙️)** → **Управление приложениями** (Manage apps / UPM).
3. Нажмите **Загрузить приложение** (Upload app).
4. Выберите файл `target/opentfc-confluence-plugin-1.0.0-SNAPSHOT.jar`.
5. Дождитесь подтверждения успешной установки.
6. Убедитесь, что в списке пользовательских приложений статус OpenTFC отображается как **Включено** (Enabled).
7. Проверьте отсутствие ошибок инициализации в логе:
   `tail -f <confluence-home>/logs/atlassian-confluence.log`

---

## 4. Конфигурация администратора

1. Откройте **Администрирование Confluence** → раздел **Настройки OpenTFC** (`/admin/opentfc/view-opentfc-admin.action`).
2. Настройте параметры:
   - **Тайм-аут SQL запроса:** 10 секунд (по умолчанию).
   - **Макс. число строк результата DuckDB:** 50 000.
   - **Белый список доменов (Whitelist):** домены для внешних CSV/JSON источников данных.
3. Нажмите **Сохранить настройки**.

## 5. Smoke-чеклист приёмочных испытаний (Раздел 12.3 ТЗ)

| № | Тестовый сценарий | Ожидаемый результат | Покрытие |
|---|---|---|:---:|
| 1 | **Table Filter**: обёртывание таблицы 500 строк | Поиск, поколоночные фильтры, сортировка (в т.ч. Shift+клик), строка итогов, пагинация; экспорт CSV/XLSX; сохранение профиля | Авто (рендер, экспорт, AO-профили) + Инстанс (UI) |
| 2 | **Table Filter + Jira Issues**: обёртывание макроса задач | Интерактивная фильтрация таблицы Jira Issues | Инстанс |
| 3 | **Chart from Table**: Column, Pie, Gantt | Диаграммы строятся по данным; реагируют на фильтры; экспорт PNG | Авто (параметры, XSS, export-режим) + Инстанс (ECharts) |
| 4 | **Pivot Table**: группировка, SUM/AVG | Сводная таблица строится динамически | Авто (параметры) + Инстанс |
| 5 | **Table Transformer**: `SELECT T1.* FROM T1` | SQL выполняется в памяти через DuckDB | Авто (JOIN/GROUP BY/UNION/окно/песочница) |
| 6 | **Table Spreadsheet**: лист, формулы SUM/AVG | Редактирование, пересчёт формул, сохранение во вложения | Авто (рендер, export-режим) + Инстанс (редактор) |
| 7 | **Spreadsheet Include** | Отображение диапазона со сторонней страницы | Авто (параметры, export-режим) + Инстанс |
| 8 | **Attachment Table**: листинг вложений | Таблица файлов со скачиванием и фильтрами по типу | Авто (метаданные, include/exclude, размеры) |
| 9 | **CSV Table**: импорт из вложения | Корректный парсинг разделителей и кодировок (UTF-8, cp1251) | Авто |
| 10 | **Права и безопасность**: XSRF и SSRF | localhost/127.0.0.1/RFC1918 блокируются; мутации без XSRF отклоняются | Авто (SSRF-гарды, 401 без пользователя) + Инстанс (XSRF) |
| 11 | **Экспорт в PDF/Word**: статичный вид | Страница со всеми макросами экспортируется в PDF/Word без сбоев | Авто (export-режим макросов) + Инстанс |
