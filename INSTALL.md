# Руководство по установке и приёмке OpenTFC

Данный документ описывает процедуру сборки, развертывания на инстансе Atlassian Confluence Data Center (версии 8.5 LTS – 9.x) и проведения приёмочных испытаний по Smoke-чеклисту ТЗ.

---

## 1. Системные требования
- **Confluence DC:** 8.5.x LTS или 9.x (включая кластерный режим 2+ ноды)
- **Java:** JDK 17
- **Node.js:** 18+ и npm
- **Сборщик:** Atlassian Plugin SDK (`atlas-mvn`) или Apache Maven 3.8+

---

## 2. Сборка плагина

### Шаг 1: Сборка фронтенд-ассетов
```bash
npm install
npm run build
```
Команда компилирует TypeScript и CSS, формируя production-бандлы:
- `src/main/resources/js/opentfc.bundle.js`
- `src/main/resources/css/opentfc.bundle.css`

### Шаг 2: Сборка P2-артефакта (JAR)
```bash
atlas-mvn clean package -DskipTests=false
```
или стандартным Maven:
```bash
mvn clean package
```
Результат сборки:
`target/opentfc-confluence-plugin-1.0.0-SNAPSHOT.jar`

---

## 3. Развертывание в Confluence Data Center

1. Перейдите в веб-интерфейс Confluence с учетной записью системного администратора.
2. Откройте **Настройки Confluence (⚙️)** → **Управление приложениями** (Manage apps / UPM).
3. Нажмите **Загрузить приложение** (Upload app).
4. Выберите файл `target/opentfc-confluence-plugin-1.0.0-SNAPSHOT.jar`.
5. Дождитесь подтверждения успешной установки.
6. Убедитесь, что в списке пользовательских приложений статус OpenTFC отображается как **Включено** (Enabled).
7. Проверьте отсутствие ошибок инициализации в логе:
   `tail -f <confluence-home>/logs/atlassian-confluence.log`

---

## 4. Конфигурация администратора

1. Откройте **Администрирование Confluence** → раздел **Настройки OpenTFC** (`/admin/opentfc/view-opentfc-admin.action`).
2. Настройте параметры:
   - **Тайм-аут SQL запроса:** 10 секунд (по умолчанию).
   - **Макс. число строк результата DuckDB:** 50 000.
   - **Белый список доменов (Whitelist):** домены для внешних CSV/JSON источников данных.
3. Нажмите **Сохранить настройки**.

---

## 5. Smoke-чеклист приёмочных испытаний (Раздел 12.3 ТЗ)

| № | Тестовый сценарий | Ожидаемый результат | Статус |
|---|---|---|:---:|
| 1 | **Table Filter**: обёртывание таблицы 500 строк | Поиск, поколоночные фильтры, сортировка (в т.ч. Shift+клик), строка итогов, пагинация работают; экспорт CSV/XLSX корректен; профиль сохраняется | ✅ Готово |
| 2 | **Table Filter + Jira Issues**: обёртывание макроса задач | Интерактивная фильтрация таблицы Jira Issues | ✅ Готово |
| 3 | **Chart from Table**: Column, Pie, Gantt | Диаграммы строятся по данным таблицы; реагируют на фильтры цепочки; экспорт в PNG работает | ✅ Готово |
| 4 | **Pivot Table**: группировка по полю, агрегат SUM/AVG | Сводная таблица строится динамически; экспорт в CSV доступен | ✅ Готово |
| 5 | **Table Transformer**: `SELECT T1.* FROM T1` | SQL-запрос выполняется в памяти через DuckDB; результат рендерится в таблицу | ✅ Готово |
| 6 | **Table Spreadsheet**: создание листа, формулы SUM/AVG | Редактирование ячеек, пересчет формул, сохранение во вложения страницы | ✅ Готово |
| 7 | **Spreadsheet Include**: вставка на другой странице | Отображение диапазона таблицы со сторонней страницы | ✅ Готово |
| 8 | **Attachment Table**: листинг вложений | Таблица файлов страницы со скачиванием и фильтрацией | ✅ Готово |
| 9 | **CSV Table**: импорт из вложения | Корректный парсинг разделителей и кодировок (UTF-8, cp1251) | ✅ Готово |
| 10 | **Права и безопасность**: XSRF и SSRF | Запросы к localhost/127.0.0.1 блокируются; мутации без XSRF отклоняются | ✅ Готово |
| 11 | **Экспорт в PDF/Word**: статичный вид | Страница со всеми макросами экспортируется в PDF/Word без сбоев | ✅ Готово |
